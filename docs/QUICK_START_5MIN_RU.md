## 2️⃣ ПОЛУЧИТЕ BOT TOKEN (2 минуты)

### Что это?
Уникальный пароль для вашего бота. Похож на: `123456789:ABCdefGHI...`

### Как получить (4 клика):

**ШАГ A - Откройте Telegram:**
```
1. Telegram приложение (на телефоне или компьютере)
↓
2. Поиск (лупа) → напишите @BotFather
↓
3. Откройте чат с BotFather
↓
4. Напишите: /newbot
```

**ШАГ B - Ответьте на вопросы:**
```
BotFather спросит: "Как назвать бота?"
Вы ответьте: INKA_Salon_Bot
(или любое другое название)

BotFather спросит: "Какой юзернейм?"
Вы ответьте: my_salon_bot
(обязательно должен кончаться на _bot)
```

**ШАГ C - Скопируйте токен:**
```
BotFather вам выдаст длинную строку:
123456789:ABCdefGHIjklMNOpqrsTUVwxyz...

Нажмите на неё → Копировать
(или выделите мышкой и Ctrl+C)
```

✅ **Готово! Токен в буфере обмена.**

## 4️⃣ СОХРАНИТЕ API KEY (1 минута)

После нажатия "ЗАВЕРШИТЬ" вы увидите:

```
✅ НАСТРОЙКА ЗАВЕРШЕНА!

Ваш секретный ключ (API Key):
┌─────────────────────────────────┐
│ sk_abc123def456ghi789xyz...     │  ← скопируйте это
└─────────────────────────────────┘

[📋 КОПИРОВАТЬ]
```

### Что делать:

1. **Нажмите** кнопку "📋 КОПИРОВАТЬ"
2. **Откройте** Notepad или Word
3. **Вставьте** (Ctrl+V) туда ключ
4. **Сохраните** файл с названием: `API_KEY.txt`
5. **Положите** его в безопасное место (папка с паролями, облако и т.д.)

**⚠️ ВАЖНО:**
- Никому не показывайте этот ключ!
- Если потеряете, будет сложно восстановить
- Этот ключ нужен для подключения платежей и интеграций
