### Шаг 2️⃣ - Получите Telegram Bot Token

**ЧТО ЭТО?** - Это уникальный пароль для вашего Telegram бота. Нужен для того, чтобы бот мог читать команды.

#### Как получить:

1. **Откройте Telegram** на телефоне или компьютере

2. **Найдите контакт @BotFather** (это официальный бот Telegram для создания ботов)
   - Нажмите на поиск (лупа)
   - Введите: `@BotFather`
   - Откройте чат

3. **Создайте новый бот**
   - Напишите: `/newbot`
   - БотFather попросит ответить на вопросы:
     - **"Как назвать бота?"** → Напишите: `INKA_Salon_Bot` (или что-то вроде этого)
     - **"Какой юзернейм?"** → Напишите: `my_salon_tatoo_bot` (обязательно должно быть `_bot` в конце)

4. **Скопируйте токен** (это длинная строка вроде `123456789:ABCdefGHI...`)
   - Нажмите на неё правой кнопкой → Скопировать
   - Или выделите двойным клико и Ctrl+C

**Готово!** Токен скопирован в буфер обмена.

## 🤖 Как пользоваться Telegram ботом (если подключили)

### После того как вы ввели Bot Token:

1. **Найдите вашего бота в Telegram**
   - Откройте Telegram

2. **Первая команда**
   - Напишите: `/start`

3. **Что умеет бот**

   - `/booking` - создать новую запись

## ⚠️ Часто задаваемые вопросы

### ❓ Я потерял Bot Token
**Решение:**
1. Откройте Telegram → @BotFather
2. Напишите `/mybots`
3. Выберите ваш бот из списка
4. Нажмите "Edit commands" или "Revoke token"
5. Создайте новый токен

### ❓ Не могу найти @BotFather
**Решение:**
1. Убедитесь, что вы в Telegram (официальное приложение)
2. Нажмите поиск (лупа внизу)
3. Напишите ровно: `@BotFather` (с символом @)

### ❓ API Key не скопировался
**Решение:**
1. Нажмите кнопку **"Копировать API Key"** ещё раз
2. Откройте текстовый редактор (Notepad, Word)
3. Нажмите Ctrl+V (вставить)
4. Если ничего не вставилось - скопируйте ключ вручную (выделите мышкой)

### ❓ Что делать, если забыл пароль от админ-панели?
**Решение:**
Обратитесь к администратору системы (тому, кто вам дал этот гайд)

### ❓ Где я вижу свои записи клиентов?
**Решение:**
1. Зайдите в админ-панель
2. Откройте вкладку **"Букинги"** или **"Записи"**
3. Там будут все записи клиентов

### ❓ Как добавить цену за услугу?
**Решение:**
Эта функция будет добавлена позже. Пока просто записывайте клиентов.
