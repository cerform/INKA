## 📱 ВОПРОСЫ О TELEGRAM БОТЕ

### ❓ ЧТО ТАКОЕ БОТ И ЗАЧЕМ ОН НУЖЕН?

**Ответ:** Бот - это автоматический помощник в Telegram.

**Что он делает:**
- ✅ Получает запросы от клиентов
- ✅ Показывает расписание вашего салона
- ✅ Принимает запись на услуги
- ✅ Отправляет напоминания

**Зачем это нужно:**
Клиенты могут записаться к вам прямо в Telegram, не заходя на сайт!

**ОБЯЗАТЕЛЕН ЛИ?**
Нет! Если не хотите подключать бот - просто пропустите этот шаг в форме.

---

### ❓ КАК ПОЛУЧИТЬ BOT TOKEN?

**Ответ (простая версия):**

```
1. Откройте Telegram
2. Найдите @BotFather (через поиск)
3. Напишите ему: /newbot
4. Ответьте на 2 вопроса (название и юзернейм бота)
5. Он вам даст длинную строку - это и есть токен
6. Скопируйте её (нажмите на строку, потом Копировать)
7. Вставьте в форму на сайте (Ctrl+V)
```

**Полная версия:** [Смотрите здесь](./USER_SETUP_RU.md#шаг-2--получите-telegram-bot-token)

---

### ❓ Я ПОТЕРЯЛ BOT TOKEN, ЧТО ДЕЛАТЬ?

**Ответ:** Не паникуйте, можно создать новый!

```
1. Откройте Telegram → @BotFather
2. Напишите: /mybots
3. Выберите ваш бот из списка
4. Нажмите на кнопку с настройками
5. Найдите "Revoke current token" (Отозвать токен)
6. Нажмите - вам выдадут новый токен
```

**Если это не сработало:**
- Удалите старого бота (/deleteme)
- Создайте нового (/newbot)

## 🔐 ВОПРОСЫ ОБ API KEY

### ❓ ЧТО ТАКОЕ API KEY?

**Ответ:** Это уникальный пароль для вашего салона.

**Для чего:**
- Платежные системы (когда клиент платит за запись)
- Интеграция с другими приложениями
- Синхронизация данных

**Как выглядит:**
```
sk_abc123def456ghi789xyz...
```

**ВАЖНО:**
- Никому не показывайте этот ключ!
- Это как пароль к вашему банковскому счету
- Если потеряете - будет сложно восстановить

---

### ❓ Я ПОТЕРЯЛ API KEY

## 🌐 ВОПРОСЫ О САЙТЕ

### ❓ САЙТ НЕ ОТКРЫВАЕТСЯ

**Ответ:** Сделайте в таком порядке:

**Действие 1:** проверьте интернет
- Откройте Google (google.com)
- Если Google открыт - интернет есть

**Действие 2:** очистите кэш браузера
- Chrome: Ctrl+Shift+Delete → удалить всё
- Firefox: Ctrl+Shift+Delete → удалить всё
- Safari: меню → Develop → Empty Web Cache

**Действие 3:** перезагрузитесь
- Закройте браузер полностью
- Перезагрузите компьютер/телефон
- Откройте браузер заново
- Попробуйте открыть сайт

**Действие 4:** попробуйте другой браузер
- Если используете Chrome - попробуйте Firefox
- Если используете Safari - попробуйте Chrome

**Действие 5:** if all else fails
- Позвоните человеку с техподдержкой

## ⏰ ВОПРОСЫ О ВРЕМЕНИ И РАСПИСАНИИ

### ❓ КАК УСТАНОВИТЬ ВРЕМЯ РАБОТЫ?

**Ответ:** На Шаге 3 формы.

Вы видите все дни недели с время (09:00 - 21:00).

- ☑️ = работаете в этот день
- ☐ = выходной в этот день

Нажмите на время если нужно изменить!

**Пример:**
```
Если вы работаете с 10:00 до 20:00:
- Нажмите на первое время (09:00)
- Измените на 10:00
- Нажмите на второе время (21:00)
- Измените на 20:00
- Готово!
```

---
