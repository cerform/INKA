🔧 TROUBLESHOOTING

If deployment fails:

1. Check authentication:
   $ gcloud auth login

2. Verify project:
   $ gcloud config get-value project

3. Check API enablement:
   $ gcloud services list --enabled

4. View build logs:
   $ gcloud builds log BUILD_ID

5. Check Cloud Run logs:
   $ gcloud run logs read inka-api --limit=100
