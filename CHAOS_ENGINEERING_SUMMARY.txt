EXECUTION MODEL
────────────────────────────────────────────────────────────────────────────────

Lifecycle:
  1. User initiates → /chaos_run api_latency_injection stage
  2. Pre-flight checks → SafetyController validates
  3. Create ChaosRun record (status=PENDING)
  4. Launch async task: _execute_loop()
  5. Enable chaos injection → _start_experiment()
  6. Poll metrics every 15s → record snapshots
  7. Check abort conditions each poll
  8. Normal completion OR abort triggered
  9. If abort → RollbackManager.rollback()
 10. Final state: COMPLETED | ROLLED_BACK | FAILED

All actions logged with experiment_id for tracing
